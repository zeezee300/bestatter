# Sicherheit

Bitte melden Sie vermutete Sicherheitslücken **nicht** als öffentliches Issue.

Nutzen Sie stattdessen die vertrauliche Meldung von GitHub: im Repository unter **Security → Report a vulnerability**. Die Meldung ist nur für die Betreuer des Projekts sichtbar.

Hilfreich sind:

- betroffene Version von „Bestatter“ und Nextcloud,
- eine Beschreibung der Lücke und ihrer Auswirkung,
- Schritte zum Nachvollziehen (ohne echte personenbezogene Daten).

Unterstützt wird jeweils die aktuelle Version.
