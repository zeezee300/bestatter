# Österreichische Vorlagen

Hier werden ausschließlich fachlich und rechtlich freigegebene österreichische DOCX-Vorlagen abgelegt.

Bundeslandspezifische Dateien liegen unter `AT/<BUNDESLAND>/`, zum Beispiel:

`AT/WIEN/STERBEFALLANZEIGE_STANDESAMT_BEARBEITBAR.docx`

Mit Version 0.51.0 werden bewusst keine vermeintlich amtlichen österreichischen Formulare mitgeliefert. Die technische Auflösung ist vorbereitet; die Inhalte müssen vor ihrer Aufnahme durch die zuständige Fachstelle bestätigt werden.
